# FreeRTOS Spacecraft Communication Simulator

An educational spacecraft communication simulator using the **FreeRTOS kernel** and its POSIX/Linux simulator port.

## Project status
**Development in progress.** The repository is being initialized, and no physical real-time guarantees or completed experimental results are claimed.

The working implementation, documented build/test procedure, and experiment plan will be developed on a feature branch and reviewed through a pull request.

## Research goal
Compare dynamic phase-aware priorities against static, equal, and inverted scheduling policies during launch, ascent, and orbit insertion. Measure telemetry, command, and emergency latency, queue depth, deadline misses, and dropped messages.

## Environment
Develop on macOS using a Linux VM/container. Linux/POSIX simulation is not a substitute for target hardware validation.

## Project contributors
Actual contributions should be attributed to the people who develop, run, review, and explain the corresponding work.
